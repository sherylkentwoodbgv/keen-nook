# keen-nook

React · Kubernetes · Distributed Systems

处理日常小任务的工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/keen-nook.git
cd keen-nook
chmod +x run.sh
```
